# [WD] Secure

Wild Designs security system for Second Life. Current release **v0.9.0**.

**Short line:** [WD] Secure - Mainland protection without ban lines.

This repository holds the public **version check file** used by inworld units. Product manuals live in the [Wiki](https://github.com/jrwild/-WD-Secure/wiki).

## Version file

`wd-secure-version.txt` is read by the inworld Update check. Leave it on `main`.

## Permissions (sold unit)

- Object / linkset: Modify / Copy / No Transfer
- Scripts: Copy / No Modify / No Transfer
- Do not deed. Group-set only.

Label: `[WD] Secure` or `[WD] Secure: Feature`
